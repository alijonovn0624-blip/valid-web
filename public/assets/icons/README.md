# Local 3D icon library

PNG files here are shown by the `AppIcon` component (src/icons.jsx). Expected names (256x256, transparent background, same 3D style):

attendance.png  ranking.png  vocabulary.png  grammar.png  homework.png  community.png
messages.png    events.png   achievements.png progress.png  points.png

Missing files are skipped automatically: the matching Lucide outline icon is shown instead, so you can add icons one at a time.
Only add images you are licensed to use (check attribution rules of the source).
